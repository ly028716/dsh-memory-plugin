# 敏感数据脱敏设计

## 目标

让插件的自动采集链路在写入本地记忆前移除常见密钥、令牌、密码、私钥和用户目录信息；保留工具使用统计、命令结构和项目名等非敏感信息。

## 范围

- 工具命令：脱敏命令行参数、环境变量赋值、HTTP Authorization、URL 查询参数、JSON 风格敏感字段和 PEM 私钥块。
- 偏好与会话内容：递归处理字符串、数组和对象；敏感字段名对应的值直接替换为 `[REDACTED]`。
- 项目上下文：将绝对路径中的用户目录名替换为 `[USER]`，保留项目目录结构和项目名。
- 自动采集默认执行脱敏；不保存脱敏前的原文，也不输出到日志。

## 设计

新增 `privacy.js` 作为纯函数模块，提供 `redactSensitiveData(value)` 和 `redactProjectPath(value)`。脱敏函数不依赖存储或 DSH，便于单元测试和后续复用。

`MemoryManager` 在以下边界调用脱敏函数：

1. `recordToolCall()` 在分析命令前处理 `args.command`。
2. `recordPreference()` 在写入偏好值前递归处理值。
3. `recordSessionItem()` 在追加主题/任务前处理内容。
4. `recordProjectContext()` 在写入路径、名称和标签前处理项目数据，其中路径额外应用用户目录脱敏。

不实现可逆加密：当前插件没有密钥管理和密钥轮换机制，伪加密会增加风险并不能替代脱敏。

## 错误处理与兼容性

- 非字符串、数组和普通对象保持类型结构；未知类型原样返回。
- 已脱敏值不会再次扩大或改变语义。
- 保留现有 `encryptSensitiveData` 配置字段以兼容旧配置，但不将其作为关闭脱敏的开关；安全脱敏始终启用。

## 验证标准

- 单元测试覆盖命令参数、环境变量、Authorization、URL 查询参数、嵌套对象、私钥块和项目路径。
- MemoryManager 测试确认敏感命令、偏好和会话内容的原文不在内存和持久化 JSON 中。
- 现有 DSH 集成、Loader、存储并发和安装回归继续通过。
